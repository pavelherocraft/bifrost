Payload Logs v1.1 (2026-08-29)

Выборочное логирование запросов пользователей: пишется только содержимое сообщений с role == "user" (без system/assistant контекста и без ответов модели), только успешные запросы, только для user_id из списка ниже. Хранение: 30 дней.

Ключ хранится в localStorage браузера. Нужен master admin ключ из /opt/litellm/.env (LITELLM_MASTER_KEY) или admin virtual key.

Allowlist — чьи запросы логировать (по user_id)

Изменения подхватываются хуком в течение ~15 секунд (кэш TTL).
