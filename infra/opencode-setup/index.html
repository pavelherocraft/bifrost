🚀Как применить настройки

Способ 1 — через агента (opencode / Hermes / другой) — рекомендуется
  1. Скопируй текст выше и вставь его агенту как сообщение — промпт в начале текста уже объясняет, что делать (обновить провайдер, использовать имеющийся ключ или запросить у тебя).
  2. Перезапусти агента — opencode читает конфиг только при старте.
  3. Готово: модели появятся в переключателе (в opencode — Tab или /models).
Способ 2 — вручную
  1. Скачай файл кнопкой выше или скопируй JSON (без первой строки-промпта).
  2. Сохрани как ~/.config/opencode/opencode.json (глобально) или opencode.json в корне проекта.
  3. Ключ передаётся через переменную окружения LITELLM_API_KEY — экспортируй её или впиши ключ прямо вместо {env:LITELLM_API_KEY}.
  4. Перезапусти opencode.
Способ 3 — агенты с динамической подгрузкой (Hermes и подобные)
  1. Открой Настройки → Model → Custom endpoint → Set up custom endpoint.
  2. Base URL: https://hcbifrost.herocraft.com/litellm/v1
  3. API Key: твой virtual key (sk-…).
  4. Connect — список моделей подтянется автоматически.

💡Подсказки по работе

⌨️
Переключение моделей — в opencode: Tab циклит модели, /models открывает полный список с поиском. Модель можно менять на ходу, контекст сохраняется.
🧠
Thinking-варианты — у reasoning-моделей есть варианты low / high / max: тот же переключатель моделей циклит их. low — быстро и дёшево для простых правок, high/max — глубже думает (и дороже, до 2× reasoning-токенов). Для рутины бери low или не-reasoning модель.
📎
Картинки и файлы — модели с vision принимают изображения как вложения (скриншоты, диаграммы). Просто прикрепи файл к сообщению.
💰
Цена — флагманы (GLM-5.3, Kimi K3, qwen3.8-max) в 10–30 раз дороже дешёвых моделей. 80% повседневных задач решают рабочие лошадки (см. гайд ниже). Не оставляй флагман включённым «по инерции».
🔄
Обновляй конфиг — состав моделей и лимиты периодически меняются. Если модель исчезла или появилась ошибка «Invalid model name» — зайди на эту страницу снова и перегенерируй конфиг.
🧹
Компакция — в конфиге включён prune: при сжатии истории opencode выкидывает устаревшие куски, а не суммаризует всё подряд. Помогает на длинных сессиях.
🔌
MCP-серверы — если указаны в summary выше, они подключаются автоматически; LiteLLM сам фильтрует tools по правам твоего ключа.
⏱️
Не опрашивай MCP-серверы чаще раза в 15 минут — лишние запросы создают нагрузку на шлюз и мусор в логах. Для периодических проверок ставь интервал ≥ 15 минут; списки моделей/инструментов кэшируются агентом и не меняются чаще.
🖼️
Картинки лучше обрабатывать субагентами — не грузи изображения в основной тред: делегируй анализ скриншотов/диаграмм субагенту (Task tool). Основной агент не засоряется визуальным контекстом, экономит токены, а субагент с vision-моделью вернёт готовое текстовое заключение.

🧭Какую модель выбрать

Актуальный модельный ряд (сентябрь 2026). Жирные — рекомендованные точки входа.

qwen3.8-maxфлагман
Самая дорогая модель — и самая умная. Плюс миллион токенов контекста: весь проект разом, гигантские файлы, длинные логи.
Kimi K3флагман №2
Второй флагман, тоже дорого. Смотрит на задачи под другим углом, чем qwen — отлично для ревью кода и разбора сложных мест.
GLM-5.3продвинутый инженер
Решает сложные задачи — архитектура, коварные баги, планирование, — но до флагманов не дотягивает. Заметно дешевле их.
MiniMax-M3рабочая лошадка
Рабочая лошадка для написания кода: девопс, повседневные задачи, багфиксы. Начинай с неё — покрывает большую часть работы.
MiniMax-M3.1-Flash-Previewновая · быстрая
Свежий preview от MiniMax (сен 2026): ultra-fast текстовая модель для повседневной разработки — быстрые багфиксы, правки, небольшие фичи.
xiaomi/mimo-v2.6-proцена/качество
Лучшее соотношение цена/качество, но чуть глупее GLM-5.3. Так же хорошо справляется со сложным кодом и заковыристыми ошибками.
stepfun/step-5-previewрабочая лошадка
Ещё одна рабочая лошадка. Свежая превью-модель StepFun с vision — агенты и мультимодальность. Пробуй, делись впечатлениями.
tencent/Hy4резервный флагман
Резервный флагман — когда основные закончились (лимиты/квоты). По возможностям близок к ним.
deepseek-v4-proсильная инженерная
Сильная модель для сложного кода — дешёвая альтернатива GLM-5.3, когда нужен «второй взгляд» без флагманских цен.
qwen3.7-maxпрежний флагман
Предыдущий флагман qwen — всё ещё очень умная, при этом максимально дешёвая в своём классе.
Kimi K2.8бюджетный Kimi
Повседневная версия Kimi: ревью, правки, аккуратные задачи — без ценника K3.
GLM-5.3-Flashбыстрая+дешёвая
Быстрая версия GLM: повседневный код, правки, быстрые ответы. Дешёвая альтернатива GLM-5.3 в большинстве случаев.
qwen3.8-flashобрезанный флагман
Заметно умнее и дороже MiniMax-M3: чуть-чуть обрезанный флагман, но всё ещё достаточно дорогая.
stepfun/step-3.7-flashдешёвая · vision
Недорогая stepfun с поддержкой картинок — скриншоты и диаграммы за копейки.
deepseek-v4.1-flashсредняя
Средняя по разумности: чуть дороже mimo-v2.6-pro и чуть медленнее.
xiaomi/mimo-v2.6-flashдокументация
Лучший выбор для текстов, доков и README. Максимально дешёвая, при этом ничего не забывает.
tencent/Kimi K3 (reserved)резерв
Резервная копия Kimi K3 на tencent-плане — когда основной K3 недоступен.
tencent/Hy3младший резерв
Младший брат Hy4 — дешевле, для случаев «флагман нужен, но не максимально умный».
MiniMax-M2.7простая
Простые механические задачи: закоммитить, проверить синтаксис, переформатировать.
highspeedускоренные
MiniMax-M2.x-highspeed — те же модели, но со значительно более быстрым инференсом.

Рекомендация: MiniMax-M3 по умолчанию → GLM-5.3 для сложного → флагманы (qwen3.8-max / Kimi K3) — когда задача того стоит.

🎨Генерация картинок

Модели перечислены в summary выше. Эндпоинты: /v1/images/generations (text-to-image) и /v1/images/edits (image-to-image, для моделей с пометкой).

Лимиты: обычные пользователи — 25 картинок/день, команда All Access — 50/день (per user × model, общий для generation и editing). Размер по умолчанию 1024x1024, переопределяется параметром size.

Пример curl 
curl -X POST https://hcbifrost.herocraft.com/litellm/v1/images/generations \
  -H "Authorization: Bearer $LITELLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-image-2", "prompt": "A cozy cabin in snowy forest", "size": "1024x1024"}'

🎙️MiniMax Media API — речь, видео, картинки

Не chat-модели — вызываются напрямую через passthrough-роуты (авторизация: твой Litellm API key, как у chat). Base: https://hcbifrost.herocraft.com/litellm

МодельТипРоут (POST, если не указано)
speech-2.8-hdTTS (40 языков, эмоции, теги)/minimax/v1/t2a_v2
voice cloneКлонирование голоса/minimax/v1/voice_clone
image-01Картинки (t2i / i2i)/minimax/v1/image_generation
MiniMax-H3 / H3-MaxВидео 768P/2K, 4–15с/minimax/v2/video_generation
video tasksСтатус задач/minimax/v2/query/video_generation (GET)
Пример: синтез речи (speech-2.8-hd)
Аудио вернётся hex-строкой в data.audio → декодируй в MP3. Голоса: platform.minimax.io/docs/faq/system-voice-id. В тексте поддерживаются паузы <#1.5#> и интеръекции (sighs), (laughs). 
curl -X POST https://hcbifrost.herocraft.com/litellm/minimax/v1/t2a_v2 \
  -H "Authorization: Bearer $LITELLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "speech-2.8-hd",
    "text": "Привет! (chuckle) Это проверка синтеза.",
    "stream": false,
    "voice_setting": {"voice_id": "female-shaonv", "speed": 1.0, "vol": 0.8, "pitch": 0},
    "audio_setting": {"format": "mp3", "sample_rate": 32000}
  }'
# hex -> mp3: python3 -c "print(open('out.json'))..." или xxd -r -p
Пример: видео (MiniMax-H3, async)
Submit возвращает task_id → полли GET-запросом, пока status не станет Success (в ответе — ссылка на файл). 
# 1. submit
curl -X POST https://hcbifrost.herocraft.com/litellm/minimax/v2/video_generation \
  -H "Authorization: Bearer $LITELLM_API_KEY" -H "Content-Type: application/json" \
  -d '{"model": "MiniMax-H3", "content": [{"type": "text", "text": "A drone shot over neon city, 768p"}]}'
# 2. poll (GET, принимает task_id параметром)
curl "https://hcbifrost.herocraft.com/litellm/minimax/v2/query/video_generation?task_id=TASK_ID" \
  -H "Authorization: Bearer $LITELLM_API_KEY"

🧩MCP-сервер media — генерация медиа для агентов

Единый MCP-сервер для агентов (opencode и любые MCP-клиенты). Если у твоей команды есть доступ — он уже включён в сгенерированный конфиг выше (секция "mcp": {"media": {...}}) и авторизуется тем же ключом LITELLM_API_KEY. Endpoint: https://hcbifrost.herocraft.com/litellm/media/mcp

ТулЧто делает
list_media_modelsКаталог моделей/голосов/форматов (агент вызывает первым)
generate_imageКартинки: gemini-3.1/pro-image, gpt-image-1.5/2/2.5-*, minimax image-01
edit_imageРедактирование картинки по инструкции (i2i), вход — URL/upload:
generate_video + video_statusВидео MiniMax (Hailuo-2.3/02, T2V-01): submit → poll → URL
synthesize_speechTTS: голоса mimo/minimax, style-инструкции, voicedesign
clone_speechРечь клонированным голосом (сэмпл wav/mp3 до 10MB)
register_voice_clonePersistent MiniMax-клон (voice_id, PAYG) → синтез через synthesize_speech; также clone_speech (xiaomi zero-shot)
transcribe_audioТранскрибация аудио (ASR)

Экономия контекста: тузы возвращают URL (https://hcbifrost.herocraft.com/media-files/…, TTL 24ч), а не base64. Цепочка image→video: URL из generate_image передаётся в generate_video.first_frame_url.

Загрузка локальных файлов (сэмпл голоса, аудио для транскрибации): POST /media-upload?name=file.wav с Bearer-ключом → получаешь ref, его передаёшь в тул как upload:….

Скорость: картинка ~10–30с, TTS ~5с, видео 1–5 мин (асинхронно). Если media нет в твоём конфиге — у команды нет гранта, попроси админа.

🛠️Если что-то не работает

СимптомЧто делать
401 AuthenticationНеверный ключ: проверь переменную LITELLM_API_KEY / введённый VK.
403 / «Invalid model name»Модели нет в твоих правах или конфиг устарел — перегенерируй его на этой странице.
429Лимиты запросов/дня — подожди или смени модель (например, на (res)-версию).
Компакция падает с 413Слишком много тяжёлых вложений в контексте — убери часть картинок из истории.
Модель «думает» слишком долгоПереключись на вариант low или на не-reasoning модель (MiniMax-M3, mimo).
